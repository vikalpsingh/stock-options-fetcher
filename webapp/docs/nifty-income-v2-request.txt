7. CENTRAL NIFTY RISK CALCULATOR
====================================================

Create/reuse a single canonical risk service:

calculate_nifty_portfolio_risk(
    existing_positions,
    proposed_strategy,
    execution_prices,
    config
)

Use this SAME service in:
- Main dashboard
- Order ticket
- Live GO validation
- Existing positions
- Strategy analytics
- Exit engine

For Bull Put Spread:

Width = Short PE Strike - Long PE Strike

Max Loss =
(Width - Net Credit Points) × Quantity

For Bear Call Spread:

Width = Long CE Strike - Short CE Strike

Max Loss =
(Width - Net Credit Points) × Quantity

For a standard same-expiry, nonoverlapping Iron Condor:

Width = MAX(PE Width, CE Width)

Max Loss =
(Width - Total Net Credit Points) × Quantity

Account for closing/transaction costs separately and include conservative estimated execution costs in pretrade exposure calculations.

For nonstandard structures, unequal quantities, overlapping wings or different expiries, use a payoff-scenario risk engine rather than applying the simple condor formula.

Different expiry risk:
- Do not automatically net calendar exposures.
- Use conservative risk aggregation.
- When loss cannot be bounded, return UNCAPPED/UNKNOWN.

Aggregate existing and new strategies conservatively.

For compatible same-expiry positions, calculate portfolio payoff by underlying price scenarios to avoid incorrect double counting.

Use an upper bound for losses when portfolio-level expiry interactions cannot be modelled reliably.

Store:

current_defined_max_loss
new_strategy_max_loss
projected_portfolio_max_loss
risk_cap
risk_remaining
uncapped_risk_present
risk_status

Hard rule:

projected_portfolio_max_loss <= ₹60,000

Also require:
uncapped_risk_present = false

Broker margin is a separate metric, never a substitute for defined maximum loss.

11. HEDGE-FIRST EXECUTION
====================================================

Order execution sequence:

Bull Put:
1. BUY lower PE hedge
2. Confirm FILLED quantity.
3. SELL higher PE up to confirmed protected quantity.

Bear Call:
1. BUY higher CE hedge.
2. Confirm FILLED quantity.
3. SELL lower CE up to confirmed protected quantity.

Iron Condor:
1. BUY PE hedge.
2. BUY CE hedge.
3. Confirm both hedge quantities filled.
4. SELL PE.
5. SELL CE.

Order acceptance alone is not equivalent to a filled hedge.

Implement execution states:

CREATED
VALIDATED

- timestamps
- status
- errors
