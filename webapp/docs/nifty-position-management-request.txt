5. FIX HEDGE ALLOCATION ENGINE
====================================================

Implement:

reconcile_nifty_hedge_allocations(positions, strategy_records)

Rules:

For a short PE:
Compatible long hedge must have:
- same NIFTY underlying
- same account
- same expiry
- same PE type
- lower strike
- positive available quantity

For a short CE:
Compatible long hedge must have:
- same underlying/account/expiry
- same CE type
- higher strike
- positive available quantity

Use persisted strategy allocations first.

Do not automatically reassign hedges already reserved by another open strategy.

If a long appears compatible but was not originally linked to a strategy:
- show "Suggested Hedge Match"
- allow confirmation
- persist allocation only after reconciliation

Never allocate the same hedge quantity twice.

Calculate:

matched_hedge_qty
unmatched_short_qty
allocated_long_qty
free_long_qty

Statuses:

FULLY_HEDGED
PARTIALLY_HEDGED
UNHEDGED_SHORT
LONG_ALLOCATED_AS_HEDGE
UNALLOCATED_LONG
HEDGE_EXPIRY_MISMATCH
UNKNOWN

Example:

Short 22000 PE = 195
Long 21700 PE = 130

If the long is available:

Protected Qty = 130
Unprotected Qty = 65
Status = PARTIALLY_HEDGED

Long 21700 PE:

Allocated Qty = 130
Free Qty = 0
Status = LONG_ALLOCATED_AS_HEDGE
